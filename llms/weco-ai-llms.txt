# Weco Documentation

> Weco is production-grade autoresearch: point it at your code and an evaluation metric, and an automated research loop (AIDE) searches, tests, and ships measurable improvements as auditable, version-controlled code.

Weco AI builds recursively self-improving AI. The `weco` CLI wraps the open-source AIDE agent with orchestration, steerability, and observability so teams can run the autoresearch loop in production — improving agent harnesses, prompts, ML models, and other performance-critical code against any metric you can measure.
